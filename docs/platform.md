# 平台差异清单

状态：模板。主目标 macOS arm64（Apple Silicon），附加 Windows 11 x64，不做 Linux。

**当前验证状态（2026-11-17）**：团队没有 Mac 真机，v1 验收以 Windows 为准；macOS 相关项一律记 **未验证**，代码用条件编译保留但不进 v1 验收，`.app`、签名、公证同样挂账。拿到 Mac 后按 [../tools/spike/MAC-RUN.md](../tools/spike/MAC-RUN.md) 跑一次即可翻回原排序。Windows 实测结论不得外推为两端结论。

> 填写规则：每一行必须能落到"代码里的哪个位置"与"怎么验证"。未验证的写 **待验证**。
> 证据列填：命令输出、构建产物路径、系统版本号或官方文档链接。
