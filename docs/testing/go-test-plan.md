## 范围原则

优先覆盖纯逻辑与边界，不追求 UI 层覆盖率：

- 必须覆盖：解析（源地址、播放地址、m3u8 与字幕文本）、播放状态机、持久化序列化与迁移、IPC 消息编解码、错误分类
- 不强制覆盖：平台适配层的系统调用封装、UI 布局

## 边界清单（必须逐条有对应用例）

- 空输入、只有空白的输入
- 超长输入、非 UTF-8 字节
- 网络返回非 200、返回空体、返回截断的 m3u8
- 超时与显式取消
- 磁盘写入失败、文件内容损坏、字段缺失的旧版配置
- IPC 消息缺字段、类型错误、未知消息类型、超大消息
