# 验收标准

状态：模板。每个功能落地时在此登记，未登记验收标准的功能不进入发版回归。

## 写法要求

一条验收标准必须能被两个人独立判定出同样结论：

- 前置条件：数据、网络、源状态
- 操作步骤：可复现的顺序，逐步编号
- 期望结果：可观测的具体表现（界面元素文案、文件是否生成、日志中的字段、进程退出码、接口调用次数）
- 反例：至少一条失败路径及其期望表现（无网、源失效、文件损坏）

禁止写法："正常显示""体验流畅""基本可用""性能良好"。
